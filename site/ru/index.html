Tessera

Форк Folia для больших выживальных серверов. Исправления и оптимизации, которых пока нет в апстриме, — каждое отдельным патчем.

Скачать Исходники Java 25 · Minecraft 26.3

Состояние

Ранняя стадия, для продакшена пока не готово. Сейчас сборка — это обычная Folia под новым именем; собственные патчи Tessera появляются в PATCHES.md по мере готовности.

Что это

Внутри Folia

Folia делит мир на регионы и тикает их в разных потоках, поэтому один сервер может занять много ядер. Tessera эту модель не трогает и регулярно подтягивает апстрим.

Мелкие отдельные патчи

Каждое изменение — свой патч с номером от 1000-, с описанием. Его легко выкинуть или отправить в апстрим.

Что берём

Фиксы дюпов и крашей, ошибки владения регионами, оптимизации, которые не меняют ванильное поведение без опции в конфиге.

Что не берём

Всё, что молча ломает плагины, написанные под Folia API.

Запуск

Возьмите *-paperclip-*.jar из Releases или из последнего запуска Release workflow. Нужна Java 25.

java -Xms4G -Xmx4G -jar server.jar --nogui

Загружаются только плагины с folia-supported: true. В Paper API уже есть планировщики Folia (getRegionScheduler(), getGlobalRegionScheduler(), getAsyncScheduler(), Entity#getScheduler()), так что плагин на них работает и на Paper, и на Tessera без изменений.

Сборка

Нужны Git и JDK 25 (если JDK нет, Gradle скачает сам).

./gradlew applyAllPatches
./gradlew createPaperclipJar   # отдельным запуском: задача появляется после патчинга

Jar лежит в folia-server/build/libs/.

ПапкаЧто патчит
folia-server/minecraft-patches/исходники Minecraft
folia-server/paper-patches/исходники сервера Paper
folia-api/paper-patches/Paper API

Правите исходники в folia-server/src/minecraft или paper-server, коммитите там, потом пересобираете патчи через ./rb.sh. Подробнее в CONTRIBUTING.md.

Нашли проблему

  • Баги, краши, лаги: откройте issue и приложите полный вывод /version.
  • Воспроизводится и на чистой Folia: пишите в PaperMC/Folia.
  • Дюпы и краш-эксплойты: только приватно, см. SECURITY.md.

Почти весь код здесь — работа команд Folia и Paper, и в первую очередь Spottedleaf, автора региональной многопоточности Folia.
