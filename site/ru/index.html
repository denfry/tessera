Tessera

Форк Folia для больших выживальных серверов. Исправления, недостающие API и оптимизации, которых пока нет в апстриме, — каждое отдельным патчем.

Состояние

Ранняя стадия, идёт тестирование, для продакшена пока не готово. Каждое изменение со ссылкой на issue апстрима описано в PATCHES.md, планы — в BACKLOG.md.

Что меняет Tessera

  • Скорборды

    Скорборд потокобезопасен: личные доски, Player#setScoreboard, команды и цели работают из любого потока, как и /team и /scoreboard.

    #25

  • События телепорта

    PlayerTeleportEvent, EntityTeleportEvent и события порталов вызываются для асинхронных телепортов, порталов и эндер-жемчуга; отмена и setTo работают.

    #490

  • Миры на ходу

    Bukkit.createWorld и unloadWorld работают на запущенном сервере.

    #134

  • Эндер-жемчуг

    Жемчуг переживает смену измерения, стазис-камеры снова работают.

    #421

  • Краши

    Debug-подписки (MiniHUD), эндер-дракон вдали от 0,0 и жители в порталах больше не роняют регионы.

    #472

  • Владение регионами

    AI мобов не трогает сущности и блоки чужого региона.

    #523

  • Сохранение

    Карты и ни разу не сохранённые игроки снова сохраняются автоматически.

    #505

  • Защита сети

    Смена протокола не блокирует потоки тика на netty, повторные пакеты конфигурации игнорируются.

    #520

Что это

Внутри Folia

Folia делит мир на регионы и тикает их в разных потоках, поэтому один сервер может занять много ядер. Tessera эту модель не трогает и регулярно подтягивает апстрим.

Мелкие отдельные патчи

Каждое изменение — свой патч после патчей Folia, с описанием. Его легко выкинуть или отправить в апстрим.

Что берём

Фиксы дюпов и крашей, ошибки владения регионами, недостающие API, оптимизации, которые не меняют ванильное поведение без опции в конфиге.

Что не берём

Всё, что молча ломает плагины, написанные под Folia API.

Запуск

Возьмите *-paperclip-*.jar из Releases или из последнего запуска Release workflow. Нужна Java 25.

java -Xms4G -Xmx4G -jar server.jar --nogui

По умолчанию загружаются только плагины с folia-supported: true; остальные можно перечислить в compat.plugins в config/tessera.yml, и они запустятся в режиме совместимости: задачи BukkitScheduler выполняются на потоке глобального региона. В Paper API уже есть планировщики Folia (getRegionScheduler(), getGlobalRegionScheduler(), getAsyncScheduler(), Entity#getScheduler()), так что плагин на них работает и на Paper, и на Tessera без изменений. Плагины, которые мы запускали на Tessera, перечислены в PLUGINS.md.

Сборка

Нужны Git и JDK 25 (если JDK нет, Gradle скачает сам).

./gradlew applyAllPatches
./gradlew createPaperclipJar   # отдельным запуском: задача появляется после патчинга

Jar лежит в folia-server/build/libs/.

ПапкаЧто патчит
folia-server/minecraft-patches/исходники Minecraft
folia-server/paper-patches/исходники сервера Paper
folia-api/paper-patches/Paper API

Правите исходники в folia-server/src/minecraft или paper-server, коммитите там, потом пересобираете патчи через ./rb.sh. Подробнее в CONTRIBUTING.md.

Нашли проблему

  • Баги, краши, лаги: откройте issue и приложите полный вывод /version.
  • Воспроизводится и на чистой Folia: пишите в PaperMC/Folia.
  • Дюпы и краш-эксплойты: только приватно, см. SECURITY.md.
