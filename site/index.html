Tessera

A fork of Folia for large survival servers. Bug fixes, missing APIs and performance patches that haven't landed upstream yet, each kept as a separate patch.

Download Source Java 25 · Minecraft 26.3

Status

Early stage, still in testing, not production-ready yet. Every change is listed with its upstream issue in PATCHES.md; what is planned next is in BACKLOG.md.

What Tessera changes

  • Scoreboards

    The scoreboard is thread safe: per-player boards, Player#setScoreboard, teams and objectives work from any thread, and so do /team and /scoreboard.

    #25

  • Teleport events

    PlayerTeleportEvent, EntityTeleportEvent and portal events fire for async teleports, portals and ender pearls; cancel and setTo work.

    #490

  • Worlds on the fly

    Bukkit.createWorld and unloadWorld work while the server is running.

    #134

  • Ender pearls

    Pearls survive dimension changes and stasis chambers work again.

    #421

  • Crash fixes

    Debug subscriptions (MiniHUD), ender dragons away from 0,0 and villagers in portals no longer crash regions.

    #472

  • Region ownership

    Mob AI no longer touches entities and blocks owned by another region.

    #523

  • Saving

    Maps and players that were never saved are autosaved again.

    #505

  • Network hardening

    Protocol switches don't park tick threads on netty; repeated configuration packets are ignored.

    #520

  • Plugins without Folia support

    Compatibility mode runs Bukkit plugins without folia-supported: their scheduler tasks and commands borrow the regions they touch, sync teleports and chunk loads work. /tessera compat shows what they do that Folia does not allow.

    COMPAT.md

  • Monitoring

    Region report API and JMX beans per region, bundled spark adapted to regions, a watchdog that names the lock a hung region waits for and the thread holding it.

    #299

  • Respawn and teleports

    PlayerRespawnEvent fires again, teleportAsync works from PlayerJoinEvent and keeps relative velocity, respawn points in other regions no longer fail.

    #337

What it is

Folia underneath

Folia splits the world into regions and ticks them on separate threads, so one server can use many cores. Tessera keeps that model as is and merges upstream regularly.

Small, separate patches

Every change is its own patch placed after Folia's, documented and easy to drop or send upstream.

What goes in

Dupe and crash fixes, region-ownership bugs, missing APIs, optimisations that keep vanilla behaviour unless a config option says otherwise.

What stays out

Anything that silently breaks plugins written for the Folia API.

Run

Grab tessera-26.3-<build>.jar (with its .sha256) from Releases: the build marked "Latest" is the stable one, every push to main is published as a pre-release. Java 25 is required.

java -Xms4G -Xmx4G -jar server.jar --nogui

By default only plugins that declare folia-supported: true are loaded; others can be listed under compat.plugins in config/tessera.yml to run in compatibility mode, with their BukkitScheduler tasks and commands on the global region thread. Paper's API already has the Folia schedulers (getRegionScheduler(), getGlobalRegionScheduler(), getAsyncScheduler(), Entity#getScheduler()), so a plugin written against them runs unchanged on Paper and Tessera. Plugins we have run on Tessera are listed in PLUGINS.md.

Build

Needs Git and JDK 25 (Gradle downloads one if it's missing).

./gradlew applyAllPatches
./gradlew createPaperclipJar   # separate run: the task appears after patching

The jar ends up in folia-server/build/libs/.

DirectoryPatches
folia-server/minecraft-patches/Minecraft sources

Edit sources under folia-server/src/minecraft or paper-server, commit there, then rebuild patch files with ./rb.sh. Details in CONTRIBUTING.md.

Reporting problems

  • Bugs, crashes, lag: open an issue with the full /version output.
  • Reproduces on stock Folia too: report it to PaperMC/Folia.
  • Dupes and crash exploits: privately, see SECURITY.md.

Almost all of the code here is the work of the Folia and Paper teams, and of Spottedleaf in particular, who designed Folia's region threading.
