Tessera

A fork of Folia for large survival servers. Bug fixes and performance patches that haven't landed upstream yet, each kept as a separate patch.

Download Source Java 25 · Minecraft 26.3

Status

Early stage, not production-ready. Right now the build is stock Folia under a new name; Tessera's own patches are listed in PATCHES.md as they land.

What it is

Folia underneath

Folia splits the world into regions and ticks them on separate threads, so one server can use many cores. Tessera keeps that model as is and merges upstream regularly.

Small, separate patches

Every change is its own patch numbered from 1000-, documented, and easy to drop or send upstream.

What goes in

Dupe and crash fixes, region-ownership bugs, optimisations that keep vanilla behaviour unless a config option says otherwise.

What stays out

Anything that silently breaks plugins written for the Folia API.

Run

Grab the *-paperclip-*.jar from Releases or from the latest Release workflow run. Java 25 is required.

java -Xms4G -Xmx4G -jar server.jar --nogui

Only plugins that declare folia-supported: true are loaded. Paper's API already has the Folia schedulers (getRegionScheduler(), getGlobalRegionScheduler(), getAsyncScheduler(), Entity#getScheduler()), so a plugin written against them runs unchanged on Paper and Tessera.

Build

Needs Git and JDK 25 (Gradle downloads one if it's missing).

./gradlew applyAllPatches
./gradlew createPaperclipJar   # separate run: the task appears after patching

The jar ends up in folia-server/build/libs/.

DirectoryPatches
folia-server/minecraft-patches/Minecraft sources
folia-server/paper-patches/Paper server sources
folia-api/paper-patches/Paper API

Edit sources under folia-server/src/minecraft or paper-server, commit there, then rebuild patch files with ./rb.sh. Details in CONTRIBUTING.md.

Reporting problems

  • Bugs, crashes, lag: open an issue with the full /version output.
  • Reproduces on stock Folia too: report it to PaperMC/Folia.
  • Dupes and crash exploits: privately, see SECURITY.md.

Almost all of the code here is the work of the Folia and Paper teams, and of Spottedleaf in particular, who designed Folia's region threading.
