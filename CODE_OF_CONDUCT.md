# Code of conduct

Tessera follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful in issues, pull requests and reviews. Criticise code and decisions, not people.
Harassment, personal attacks, slurs and posting someone's private information are not allowed.

## Reporting

If someone behaves in a way that breaks these rules, report it privately to the maintainer,
[@denfry](https://github.com/denfry), through a
[private advisory](https://github.com/denfry/tessera/security/advisories/new) marked "Code of conduct",
or to the e-mail address on the maintainer's GitHub profile. Reports are kept confidential.

The maintainer may edit or remove comments, lock threads and block accounts that break these rules.
